# macOS desktop platform

This directory is reserved for the native macOS host generated by Flutter. macOS is not the primary assignment target; Android is the recommended development and demonstration platform for this repository.

## Requirements

A macOS build requires:
- A compatible Flutter SDK with macOS desktop enabled.
- macOS and Xcode.
- The Xcode command-line tools and any required signing configuration.
- CocoaPods when required by the installed Flutter plugins.

## Generate or refresh the runner

On a supported Mac, from the repository root:

~~~bash
flutter config --enable-macos-desktop
flutter create --platforms=macos .
flutter pub get
~~~

Review all generated project and signing changes before committing. Keep certificates, private keys, provisioning assets, and machine-specific settings out of Git.

## Build

~~~bash
flutter build macos
~~~

An Android CI build does not validate macOS compilation. Test the application on a Mac before claiming this target is ready.
