# Android platform

The Android runner is generated by Flutter for the package `bloc_assignment_app` and application ID `com.example.bloc_assignment_app`.

Open the repository root in Android Studio. Regenerate this folder with Flutter when SDK templates change; do not manually replace Gradle plugin versions without checking the Flutter/AGP/Kotlin compatibility matrix.

Local files such as `local.properties`, `key.properties`, `google-services.json`, signing keystores and passwords must remain untracked. The CI bootstrap job generates the full runner and standard Gradle wrapper when they are missing.

Run on an Android emulator or phone with `flutter run`. This is the assignment's primary platform.
