# Linux desktop platform

This directory is reserved for the native Linux host generated by Flutter. It is a secondary platform scaffold; the primary assignment development and demonstration target is Android.

## Toolchain

A Linux desktop build requires:
- A supported Flutter SDK with Linux desktop enabled.
- The Linux desktop development packages and compiler toolchain required by Flutter.
- CMake, Ninja, and GTK development dependencies as required by the installed Flutter version.

## Generate or refresh the runner

From the repository root on a compatible Linux environment:

~~~bash
flutter config --enable-linux-desktop
flutter create --platforms=linux .
flutter pub get
~~~

Review any generated changes before committing. Do not use regeneration to overwrite intentional platform configuration without checking the diff.

## Build

~~~bash
flutter build linux
~~~

The availability of this README does not mean a Linux runner has been built or tested. Validate the target on a supported Linux machine before describing Linux desktop support as verified.
