# Windows desktop platform

This directory is reserved for the native Windows host generated by Flutter. It is a secondary target; the primary assignment workflow uses Android Studio and an Android emulator or device.

## Requirements

A Windows desktop build requires:
- A compatible Flutter SDK with Windows desktop enabled.
- Visual Studio with the Desktop development with C++ workload.
- The Windows SDK and native build tools required by the Flutter version.

Visual Studio Code by itself is not a replacement for the Visual Studio C++ toolchain.

## Generate or refresh the runner

From the repository root in PowerShell:

~~~powershell
flutter config --enable-windows-desktop
flutter create --platforms=windows .
flutter pub get
~~~

Review generated files before committing. Protect any existing custom native configuration when regenerating the platform folder.

## Build

~~~powershell
flutter build windows
~~~

The Windows runner should be validated on a supported Windows machine. A passing Android build or the presence of this README does not prove that the Windows desktop target compiles or runs successfully.
